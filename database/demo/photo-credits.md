# Demo shop photographs

The sample grocery shop uses real photographs so the shop fronts can be judged
with real food on the shelves. Every one is from [Wikimedia
Commons](https://commons.wikimedia.org) under a free licence, listed below.

These are **demo data only**. A real shop uploads its own photographs, and
none of this is involved in a live shop. If any of these pictures are ever
shown outside a demo, the licence below has to be honoured — the CC BY and
CC BY-SA ones require crediting the photographer.

Each file's page, with its author and full licence terms, is at
`https://commons.wikimedia.org/wiki/File:<name>`.
